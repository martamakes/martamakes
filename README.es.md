## Proyecto destacado: Distrify.me

**Un SaaS de distribución y marketing musical para artistas independientes de España y Latinoamérica.** Soy la única ingeniera: producto, arquitectura, código, despliegue y soporte.

| | |
|---|---|
| **En producción** | 3 años |
| **Usuarios** | Más de 150 artistas que distribuyen y cobran a través de la plataforma |
| **Rol** | Fundadora, product owner, ingeniera full-stack y operaciones |

**Aspectos técnicos destacados**

- **Pagos y créditos con Stripe:** gestión idempotente de webhooks, lógica de reintentos y registro de auditoría. En los flujos de dinero "casi siempre funciona" no vale.
- **Seguridad en CI/CD:** escaneos automáticos con OWASP ZAP en GitHub Actions en cada despliegue.
- **Flujos de marketing con IA:** integraciones con la API de Claude que generan materiales de campaña para los artistas.
- **Diseñado para la operación real:** herramientas de soporte, permisos, casos límite y trazabilidad, no solo el happy path.

**Stack:** TypeScript · React · Next.js · Prisma · PostgreSQL (Neon) · Redis · Stripe · GitHub Actions · Vercel · Cloudflare
